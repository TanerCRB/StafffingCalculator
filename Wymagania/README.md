## Rozszerzenie UI-15 — Roles & rates

UI-15 przedstawia jeden widok katalogu: stawki oraz słowniki Roles, Seniorities, Locations, Engagement types i Vendors. Cztery powiększenia pokazują panele dodane do galerii:

- [Roles](UI/Proposal/screens/15-catalog-roles.png)
- [Seniorities](UI/Proposal/screens/15-catalog-seniorities.png)
- [Locations](UI/Proposal/screens/15-catalog-locations.png)
- [Engagement types](UI/Proposal/screens/15-catalog-engagement-types.png)

Makiety opisują aktualny zakres implementacji katalogu. Wartości na grafikach są przykładowe, a formularze prototypu nie zapisują danych do aplikacji.
